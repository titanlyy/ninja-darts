# Provider logos

Official brand artwork, used only to identify machine providers.
Ninja Darts is independent and is not endorsed by either provider.

- DARTSLIVE logo: https://www.dartslive.com/wp-content/themes/dartslive/images/logo.svg
- Phoenix Darts logo: https://www.phoenixdarts.com/images/common/logo_header.png?v=0.0.3

The `*-symbol.png` files are crops of the standalone symbols from those
wordmarks, placed on square white canvases. Symbols are not redrawn. Full
wordmarks remain in venue details; map markers use symbols without text.

Copyright and trademark rights remain with their respective owners. This
identification use is not a grant of a licence or a claim of affiliation.
